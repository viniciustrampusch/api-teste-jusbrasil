# Review remediation

Follow the `review-remediation` skill in `.cursor/skills/review-remediation/`.

Use the latest review report or the open pull-request comments as input. Implement mandatory findings only. Do not implement optional recommendations unless they were explicitly approved. Do not commit or change pull-request state unless the user asks. Update the status of each finding with evidence.
