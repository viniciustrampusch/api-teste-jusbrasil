# Code review

Follow the `code-review` skill in `.cursor/skills/code-review/`.

Review the current change against the original requirements. Do not modify files. Do not commit, merge, or approve a pull request. Produce the report from the skill template and a remediation plan. Publish pull-request comments only when an open pull request already exists and the GitHub integration can comment.
